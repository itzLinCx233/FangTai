# 方太个性化膳食规划 Agent · 部署文档

## 1. 系统概览

基于大语言模型（GLM-5.3-flash）+ GPU 混合检索（BM25 + bge 向量 + bge 重排）的个性化健康膳食推荐系统。

- **后端**：FastAPI（SSE 流式），Python 3.10+
- **RAG**：阿里云百炼 API（text-embedding-v4 嵌入 + gte-rerank 重排），无需本地 GPU；
  BM25 本地内存索引，云 API 异常自动降级；可切本地 GPU 模式（RAG_PROVIDER=local）
- **LLM**：OpenAI 兼容协议（默认智谱 glm-5.3-flash，思考强度可调）
- **前端**：内置 Web 聊天界面（`/`）

## 2. Docker 部署（推荐，评测环境）

前置要求：Docker Compose v2（**无需 GPU**，RAG 走阿里云百炼 API）。

先把 `docker-compose.yml` 中两个密钥替换为你自己的：
- `LLM_API_KEY`：智谱开放平台 https://open.bigmodel.cn
- `DASHSCOPE_API_KEY`：阿里云百炼控制台 https://bailian.console.aliyun.com（sk- 开头）

```bash
docker compose up -d --build
```

- 服务地址：`http://<host>:8000`，Web 界面在根路径
- 首次启动会调百炼 API 构建菜谱向量索引（2000 条 / 200 次调用，约 2-3 分钟），
  已挂载 volume 缓存，后续启动秒级就绪
- 健康检查：`curl http://127.0.0.1:8000/api/health`（`rag_provider` 应为 dashscope、`vector: ready`）

### 关键配置项（docker-compose environment 段）

| 变量 | 说明 | 默认 |
|---|---|---|
| LLM_BASE_URL | OpenAI 兼容端点 | 智谱 paas/v4 |
| LLM_API_KEY | API 密钥 | 部署时替换 |
| LLM_MODEL | 主模型（方案说明生成） | glm-5.3-flash |
| LLM_FAST_MODEL | 轻任务模型（槽位抽取/选菜） | glm-5.3-flash |
| LLM_THINKING | 思考强度 disabled/low/**high**/max | high（质量优先） |
| RAG_PROVIDER | dashscope（云端）/ local（本地 GPU） | dashscope |
| DASHSCOPE_API_KEY | 阿里云百炼密钥 | 部署时替换 |
| DASHSCOPE_EMBED_MODEL | 云端嵌入模型 | text-embedding-v4 |
| DASHSCOPE_RERANK_MODEL | 云端重排模型（空串禁用） | gte-rerank |
| RECALL_TOPK / RERANK_TOPK | 召回/重排候选数 | 60 / 20 |

评测环境无外网时：切本地 GPU 模式（RAG_PROVIDER=local），Dockerfile 换
`pytorch/pytorch:2.5.1-cuda12.1-cudnn9-runtime` 基础镜像并追加安装
`requirements-local.txt`，提前挂载离线模型目录。

## 3. 用户系统与管理后台

- 聊天页 `http://<host>:8000/`：右上角"登录/注册"（注册时可绑定健康档案，登录后推荐自动应用其约束，
  个人中心可设同餐人档案实现多人宴请）；匿名仍可使用（评测兼容）
- 管理后台 `http://<host>:8000/admin`：管理员专用——仪表盘统计、用户增删改查（搜索/分页/重置密码/
  启用禁用/角色调整）、会话记录查看
- 管理员账户：首次启动自动创建 **admin / admin123**（已存在则跳过），可经 `ADMIN_USERNAME` /
  `ADMIN_PASSWORD` 环境变量覆盖，后台可改密码
- MySQL：compose 已内置 mysql:8.4 服务（数据卷 `mysql-data` 持久化）；连接参数见 `MYSQL_*` 环境变量；
  评测环境无 MySQL 时给应用设 `MYSQL_ENABLED=false`，核心评测端点不受影响
- 安全实现：pbkdf2 密码哈希（12万轮加盐）+ HMAC-SHA256 签名 token（7 天有效期），均为标准库零依赖

## 4. 本地开发运行（Windows/Linux）

```bash
pip install -r requirements.txt

# 环境变量（等效于 compose 的 environment 段）
set LLM_API_KEY=xxx
set DASHSCOPE_API_KEY=sk-xxx
set LLM_MODEL=glm-5.3-flash
set LLM_THINKING=high

python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

首次启动自动调百炼 API 构建索引；也可离线预构建：`python scripts/build_index.py`

## 5. API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/chat | 多轮对话，SSE 流式（intent → plan → delta* → done） |
| POST | /api/recommend | 单次推荐，JSON 返回（便于程序集成/评测） |
| GET | /api/recipes?q=&limit=&offset= | 菜谱库检索 |
| GET | /api/recipes/{id} | 菜谱详情（含结构化食材/标签/分类） |
| GET | /api/profiles?kind=detailed\|simple | 50 份健康档案 |
| GET | /api/sessions/{sid} | 会话状态（约束栈/当前方案，可审查多轮一致性） |
| GET | /api/health | 健康检查（RAG provider/索引状态） |
| POST | /api/auth/register · /api/auth/login | 注册 / 登录（返回 token） |
| GET/PUT | /api/auth/me · /api/auth/profile | 个人资料查看 / 修改（昵称/档案/密码） |
| GET | /api/auth/sessions[/{sid}/messages] | 我的历史会话与聊天记录 |
| GET/POST/PUT/DELETE | /api/admin/users | 管理员用户增删改查（搜索/分页） |
| GET | /api/admin/stats · /api/admin/sessions[/{sid}/messages] | 统计 / 会话记录 |

### /api/chat 请求

```json
{"message": "今晚吃啥比较好？", "session_id": null, "profile_ids": [3], "reset": false}
```

`profile_ids` 支持多选（多人宴请场景，约束自动取交集）。响应头 `X-Session-Id` 返回会话号，
后续轮次带上即可延续上下文。SSE 事件：

```jsonc
{"type":"intent","slots":{...}}                      // 本轮槽位理解
{"type":"plan","dishes":[...],"nutrition_per_person":{...},"constraints_applied":"..."}  // 结构化方案（机器可校验）
{"type":"delta","text":"..."}                        // 正文流式增量
{"type":"clarify","question":"..."}                  // 模糊需求主动澄清
{"type":"done","stats":{"first_event_s":..,"total_s":..}}
```

## 6. 评测与测试

```bash
python scripts/eval.py --api http://127.0.0.1:8000   # 20 组对话用例全量评测
python scripts/eval.py --api http://127.0.0.1:8000 --case 20   # 单用例
python tests/test_core.py                            # 核心模块单元测试
```

评测输出（eval_report.json）含：首 Token 延迟 / 单轮端到端 / 多轮平均 / 过敏违反数 /
幻觉菜名数 / 零违反通过率，并对性能指标按赛题"优秀/合格"档位评级。

## 7. 目录结构

```
app/
  main.py            FastAPI 入口（启动预热）
  config.py          配置（全部读环境变量）
  core/
    llm.py           LLM 抽象层（多 provider、流式、思考格式自动探测）
    recipe_store.py  菜谱加载清洗/食材结构化/分类
    constraint_engine.py 过敏原与疾病忌口（双遍校验）
    retriever.py     BM25+向量+重排混合检索（dashscope 云端 / local GPU 双模式）
    nutrition.py     营养估算 + 份额自适应
    planner.py       整桌组合优化（荤素比/多样性/按人营养）
    dialog.py        多轮状态机（约束栈/最小化修改）
    agent.py         Agent 编排（选菜零幻觉/后校验/SSE）
  api/routes.py      REST/SSE 路由
  web/index.html     Web 聊天界面
scripts/
  build_index.py     离线索引构建
  eval.py            自动评测 harness
  dev_run.py         开发调试脚本
tests/test_core.py   单元测试
data/                菜谱库 + 健康档案 + 对话用例
```
